{{- if eq .Key "views" }} {{- if .Individual }}

People who opened the e-mail, each counted once per campaign, when they first opened it.

{{- else }}

Times the e-mail was opened. Individual tracking is off, so someone who opened it three times counts three times.

{{- end }}

An open is seen when the e-mail's images load. Mail apps that block images aren't counted, and Apple Mail loads them for most of its users whether they read it or not.

{{- else if eq .Key "clicks" }} {{- if .Individual }}

People who clicked a link in the e-mail, each counted once per campaign, when they first clicked.

{{- else }}

Clicks on the e-mail's links. Individual tracking is off, so someone who clicked three times counts three times.

{{- end }} {{- else if eq .Key "bounces" }}

E-mails that couldn't be delivered, and spam complaints: hard bounces (the address doesn't exist), soft bounces (a passing failure, such as a full mailbox) and complaints (marked as spam). Each one recorded counts.

{{- else if eq .Key "links" }} {{- if .Individual }}

Each link in the e-mail, with how many people clicked it. Someone who clicked it more than once, or in more than one of these campaigns, counts once.

{{- else }}

{{- end }} {{- end }}
